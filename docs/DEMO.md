# 答辩演示脚本

> 目标：8 分钟内完整展示「预约 → 工单 → 改约 → 完工 → 评价 → 结算」闭环。
>
> 演示前请确认已经按 [README.md](../README.md) 启动后端和前端。

## 一、演示前检查（1 分钟）

### 1. 需要启动的服务

```text
MySQL 8
后端：http://localhost:8080
前端：http://localhost:5173
```

### 2. 建议先重置一次演示数据

仅限演示数据库：

```bash
mysql -uroot -p -e "DROP DATABASE IF EXISTS nail_demo;"
```

重启后端后会重新写入 `data.sql` 的种子数据。

### 3. 账号

```text
管理员：admin / 123456
美甲师：staff1 / 123456（另有 staff2、staff3，密码相同）
顾客：cust1 / 123456（另有 cust2 ~ cust4，密码相同）
```

### 4. 建议准备

- 一个浏览器窗口即可，按“管理员 → 美甲师 → 顾客 → 管理员”切换。
- 如果不想反复退出登录，可以准备三个浏览器配置文件/隐身窗口，但不要共用同一个 localStorage。
- 提前打开登录页：`http://localhost:5173/login`。
- 提前准备一张本地图片，用于演示完工图上传。

| 时间 | 内容 |

| 0:00–0:40 | 开场、管理员首页、今日物料 |

| 1:30–2:40 | 生成结算 4202、确认结算 |

## 三、完整演示流程

### 第 1 步：管理员档期与今日物料（0:00–0:40）

1. 使用 `admin / 123456` 登录。
2. 默认进入「档期」月表，先讲这一屏：
   - 今天几号、当天几单、几位美甲师在岗；
   - 每个日期格里的时间条对应美甲师颜色，右下角细条是当天档期占用率；
   - 右上角「月 / 周」可切换，选中日期后右侧是当天在岗美甲师、可约时段与当日订单。
3. 顶部导航切换模块：

```text
档期 / 物料准备 / 评价 / 预约管理 / 薪酬规则 / 月度结算
```

4. 点「物料准备」：顶部是「每 3 天一段」的日期段，默认只显示今天所在的一段（10.23–25），日期段多了会折叠成「更多 N 段」，点「全部」可看未来 30 天。展示今天 16:00 的已确认预约：
   - 顾客：小李
   - 美甲师：小王
   - 款式：今日演示款：裸粉细闪
   - 效果图：正常显示
   - 工单状态：已就绪

5. 在物料行右侧点「确认已备好」，状态从「待准备」变为「已就绪」；误点可在同一位置「撤回」。

讲解点：

> 物料按已确认预约汇总，包含款式说明、效果图和内部物料 JSON；管理员可以直接确认备料状态，不用等美甲师改。
>
> 档期月表把“排班、预约、请假”压缩到一张表里：管理员看全店，美甲师只看自己，顾客只看还有空的美甲师。

### 第 2 步：评价与薪酬规则（0:40–1:30）

1. 点击“评价”：
   - 展示 2 条好评、1 条差评；
   - 展示评分、内容、图片。

2. 点击“薪酬规则”：
   - 美甲师小王；
   - 底薪 3500.00；
   - 提成比例 30%；
   - 好评奖励 50.00；
   - 差评扣减 100.00；
   - 编辑时美甲师字段不可更改。

> 说明：种子里的规则是底薪 3500、提成 30%、好评 +50、差评 -100。

### 第 3 步：生成初始结算（1:30–2:40）

1. 点击“月度结算”。
2. 选择当前月份。
3. 点击“生成结算”。

预期结果：

```text
完成单数：3
总营收：2440.00
提成：732.00
好评：2 条，奖励 100.00
差评：1 条，扣减 100.00
爽约：3 次，扣款 30.00
最终工资：4202.00
状态：草稿
```

4. 点击该行“确认结算”：
   - 状态变为“已结算”；
   - 记录结算时间。

讲解点：

> 结算生成后是快照。后续预约、评价、爽约发生变化，不会自动修改已结算数据。

### 第 4 步：撤销爽约与快照重算（2:40–3:50）

1. 点击“预约管理”。
2. 将状态筛选为“爽约”。
3. 任选一条爽约预约，点击“撤销爽约”并确认。
4. 状态仍显示“爽约”，但出现“已豁免”标签。

5. 回到“月度结算”：
   - 点击“生成结算”；
   - 因为该月已 SETTLED，系统会提示“该月已结算，已跳过”，不会覆盖 4202。

6. 点击该行“撤销”：
   - 状态回到“草稿”；
   - 结算时间清空。

7. 再次点击“生成结算”：

预期结果：

```text
爽约：2 次
爽约扣款：0.00
最终工资：4232.00
状态：草稿
```

讲解点：

> 撤销爽约只改变豁免标记，预约仍保留 NO_SHOW 历史；结算必须撤销后重新生成，不能直接改已结算快照。

### 第 5 步：美甲师审批与完成服务（3:50–5:10）

1. 退出管理员，使用 `staff1 / 123456` 登录。
2. 点击“我的工资”：
   - 展示 2026-10（或当前月份）；
   - 最终工资 4232.00；
   - 状态草稿；
   - 展开行可看到底薪、提成、好评奖励、差评扣减、爽约扣款、保底前应得和最终工资。

3. 点击“预约管理”：
   - 默认筛选“待确认”；
   - 看到明天 10:00 的待确认预约；
   - 点击“通过”。

4. 将筛选改为“已确认”：
   - 打开今天 16:00 的预约；
   - 点击“开始服务”；
   - 确认后预约进入“服务中”。

5. 将筛选改为“服务中”：
   - 再次打开该预约；
   - 点击“完成服务”；
   - 填写订单金额 `880`；
   - 上传一张完工图；
   - 点击“确认完成”。

讲解点：

> 完成服务时必须填写订单金额，后续结算按这个金额计算业绩；完工图用于顾客查看和留档。

### 第 6 步：顾客接受改约与评价（5:10–6:30）

1. 退出美甲师，使用 `cust1 / 123456` 登录。
2. 点击“我的预约”。
3. 找到明天 13:00 的“改约中”预约：
   - 打开详情；
   - 看到美甲师发起的改约；
   - 点击“接受”；
   - 预约改到 15:00。

4. 找到今天 16:00 的预约：
   - 打开详情；
   - 查看刚上传的完工图；
   - 点击“评价服务”；
   - 选择 5 星；
   - 填写评价内容，例如“颜色和细节都很满意”；
   - 提交评价。

5. 找到前天 10:00 的已完成预约：
   - 展示种子完工图；
   - 展示效果图；
   - 展示已有 5 星评价和评价图片。

讲解点：

> 顾客只能评价自己的已完成预约；评价会跟着预约归属到实际完成月份，而不是按评价创建时间另算一个月。

### 第 7 步：管理员重新生成结算（6:30–7:40）

1. 退出顾客，重新使用 `admin / 123456` 登录。
2. 点击“月度结算”。
3. 当前月份结算仍是“草稿”，点击“生成结算”。
4. 如果提示已有记录，确认“重新生成”。

预期结果：

```text
完成单数：4
总营收：3320.00
提成：996.00
好评：3 条，奖励 150.00
差评：1 条，扣减 100.00
评价调整：+50.00
爽约：2 次，扣款 0.00
最终工资：4546.00
状态：草稿
```

5. 可选：点击“确认结算”，再点击“撤销”，展示状态双向流转。

### 第 8 步：收尾（7:40–8:00）

总结三个技术点：

1. **预约与时间槽**：15 分钟粒度、悲观锁、审批/改约/完成状态一致。
2. **评价与结算归属**：评价按预约 `actual_end` 所在月统计，不按 `review.created_at`。
3. **结算快照**：DRAFT 可重算，SETTLED 必须撤销后才能重算；金额全部按 2 位小数 `HALF_UP`。

## 四、预期数字速查

### 初始状态

```text
底薪 3500
完成 3 单，营收 2440
提成 30% = 732
好评 2 × 50 = 100
差评 1 × 100 = 100
爽约 3 次，floor(3/3) × 30 = 30

最终工资 = 3500 + 732 + 100 - 100 - 30 = 4202
```

### 撤销 1 条爽约

```text
爽约 2 次，扣款 0
最终工资 = 3500 + 732 + 0 - 0 = 4232
```

### 完成 9004（880 元）+ 5 星好评

```text
完成 4 单，营收 3320
提成 30% = 996
好评 3 × 50 = 150
差评 1 × 100 = 100
评价调整 = +50
爽约 2 次，扣款 0

最终工资 = 3500 + 996 + 50 = 4546
```

> 如果演示时没有撤销爽约，则第 7 步最终工资为 4516；如果订单金额或评价不同，以页面实际计算为准。

## 五、常见翻车点

### 1. 结算月份选错

种子数据使用当前月份。若当前日期接近月初，历史完成单可能落在上个月，请在月份选择器中选对应月份。

### 2. 生成结算提示“已结算，已跳过”

这是正常的快照保护。先点击该行“撤销”，再生成。

### 3. 页面看不到种子数据

- 确认 `spring.sql.init.mode=always`；
- 确认数据库是新的 `nail_demo`；
- 种子使用固定 ID 9001 起，若已有同 ID 数据会跳过；
- 执行“重置演示数据”后重启后端。

### 4. 演示图片不显示

- 确认 `frontend/public/demo/` 下存在 SVG；
- 通过 Vite `http://localhost:5173` 访问，不要直接打开 `dist/index.html`；
- 后端上传图仍通过 `/uploads` 访问。

### 5. 完工图上传失败

- 检查图片格式：jpg/jpeg/png/webp；
- 检查大小：单张不超过 5MB；
- 检查后端 `uploads` 目录可写；
- 检查 Vite `/uploads` 代理。

### 6. 登录后马上跳回登录页

- 后端未启动或端口不一致；
- JWT 过期；
- 浏览器 localStorage 中有旧 token；
- 清除 localStorage 后重新登录。

## 六、演示结束后的清理

```bash
mysql -uroot -p -e "DROP DATABASE IF EXISTS nail_demo;"
```

重启后端，等待种子数据写入完成后再打开前端。
