# 单人美甲工作室版 · V0.8.0

> 单人版的「档期 + 现金流」台账。老板 = 美甲师 = 唯一使用者。
> 分支 `feat/solo-studio`；答辩版本在 `main`。

## 它能回答什么

1. **今天给谁做、做什么款、要多久？** —— 今日作业单，时间轴 + 空档
2. **材料买了没有、够不够？** —— 今天要买的料（按当天预约的材料清单聚合，与库存对比）
3. **定金收了没有、这单退不退？** —— 定金四条流水，退定/没收都是显式动作
4. **这个月收入支出对得上吗？** —— 三本流水 + 月度对账

它**不是** SaaS，**不面向客户**，**不做营销**：没有客户账号、没有员工、没有多店、没有角色权限。

## 快速开始（本地）

环境：JDK 17、Maven 3.8+、Node 18+、MySQL 8（或 MariaDB 10.6+）。

```bash
# 1. 后端（schema 与种子数据在启动时自动执行，脚本幂等）
cd backend
mvn spring-boot:run      # http://localhost:8080

# 2. 前端
cd ../frontend
npm install
npm run dev              # http://localhost:5173
```

打开 `http://localhost:5173`，用 `admin / 123456` 登录（登录页有「填入演示账号」）。
数据库连接在 `backend/src/main/resources/application.yml`，默认 `root/123456`，
库名 `nail_demo`，URL 带 `createDatabaseIfNotExist=true`，首次启动会自动建库建表。

想直接看到「有数据的样子」，登录后去 **设置 → 一键生成演示数据**（或 `POST /api/solo/demo`）：
3 位客户、5 个款式、今天 4 单（含 1 单连做，并留出空档）。

## 页面与路由

```
/solo/login      专用登录（一个账号）
/solo/today      今日作业单（首页）
/solo/schedule   周排期 + 插队 / 顺延 / 待通知清单
/solo/clients    客户档案（列表 / 详情）
/solo/styles     款式库 + 导出案例图      （二级）
/solo/materials  物料库存 + 今天要买的料   （二级）
/solo/finance    三本流水 + 月度对账       （二级）
/solo/settings   营业模板 / 缓冲 / 定金 / 改期阈值 / 导入导出 / 演示数据（二级）
```

手机（< 900px）走底部三入口；电脑（≥ 900px）导航进报头，列表与作业单转多栏。

## 技术栈与本版范围

- 后端：Java 17 / Spring Boot 3.2 / Spring Data JPA / Spring Security + JWT / MySQL 8

## 已知限制

1. **单账号**：不支持多用户，登录后所有数据都归老板。
2. **完成单不自动写尾款收入**：由「财务 → 记一笔」手动录入，避免金额算错时对不上账。
3. **改期后的待通知**只在排期页展示与标记，尚未并进「今天要发的微信」分组。
4. **不代发微信**：系统只生成话术，发送动作由人完成（brief 明确不做通知通道）。
5. **款式材料清单与库存按名称匹配**：物料改名后，历史款式清单不会自动跟随。
6. 详见 [P8-验收清单.md](P8-验收清单.md) 的「遗留与说明」。
