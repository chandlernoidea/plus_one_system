## 2. 提醒：今天要发的微信

每天三组，每组带一句现成话术，点一下就复制：

```
昨日未确认 1
  昨日未确认 10:00 #C002 阿岚
  Hi 阿岚，昨天 10:00 的档期没等到你，还好吗？想改天的话我帮你重新排～
  [复制话术]
今天 1
  今天 12:00 #C002 阿岚
  Hi 阿岚，今天 12:00 的档期还留着，现在过来还来得及，来不了咱们改天～
明天 2 …
```

分组口径：

| 组 | 取哪些单 |
|---|---|
| 昨日未确认 | 昨天还没结账的：已定档 / 已到店 / 服务中 / 待定金 |
| 今天 | 今天未到店（已定档 / 待定金）；已过点的话术换成「还来得及吗」 |
| 明天 | 明天的已定档 / 待定金 |

待定金的单话术自动带定金金额（读设置）。系统只提醒老板，不代发微信。

![提醒](docs/screenshots/solo-reminders.png)

## 3. CSV 导入客户

列顺序：`昵称, 手机后四位, 来源, 备注`，第一行是表头会自动跳过。

- 手机上从微信/Excel 复制一段贴进来即可，不用先存文件；
- **先预览再入库**：显示前 5 行，同名行标黄并写「同名，建议加区分词」；
- 手机后四位不是 4 位数字的行判为无效，导入时跳过；
- 短号接着往后发，导 20 条不会有重复短号。

## 4. 设置

| 项 | 默认 | 影响 |
|---|---|---|
| 营业时间模板 | 08:30–22:30 | 当天没单独排营业段时，作业单按这个区间画时间轴 |
| 默认缓冲 | 20 分钟 | 建单不填缓冲时带出的值 |
| 定金 | 30 元 | 收定金时的默认/上限金额 |
| 免费改期阈值 | 48 小时 | 距开始 ≥ 阈值且未用过免费改期，改期才免费 |

改完立刻生效（下次建单/排期按新值）。**导出**三个 CSV（客户 / 预约 / 流水），带 BOM、CRLF，Excel 双击不乱码。
**一键演示数据**：3 客户、5 款式、今天 4 单（含 1 单连做猫眼+手绘，并留出空档）；已有演示数据时不重复建。

## 6. 设计取舍

1. **CSV 走「文本」而不是「文件上传」**。手机上的真实场景是从微信里复制一段表格；要人先存成文件再选文件，多两步。
2. **同名不阻断导入**。老板可能有俩「小满」，系统标黄提示，导进去由人自己加区分词；导入完给短号区间方便回找。
3. **演示数据幂等**。按「演示-」前缀判断，重复点不会建两套；换环境一条 `curl -X POST /api/solo/demo` 就有可演示的数据。
4. **设置只影响之后的单**。已建好的单保留当时的缓冲快照（`buffer_minutes` 落在订单上），改设置不会把历史单的时长改掉。
